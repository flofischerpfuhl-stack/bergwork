## Forks

Forks are welcome. A fork, and every modified copy, stays under this same
license with the same conditions. Forks must not use the berg:work name or
logo, because the license grants no trademark rights.

## Relation to Fernwork and Himmel:CAD

berg:work PDF and berg:work Image build on editors developed in
[Fernwork](https://fernwork.net). Fernwork and Himmel:CAD use this same license
with the same free-of-charge cases, so code taken over from either project
keeps the same conditions.
