# Logo proposals 2026-09-25 (not approved)

Low-poly granite set in the style of the Himmel:CAD Builder mark. Greys are neutral with a slight warm tint (`#F4F3F0` to `#1D1D1C`), so they sit next to the site's cream. Each `-red` variant adds one accent in the site red `#C81E1E`.

| File | Proposal |
| --- | --- |
| `bergwork-mark(-red).svg` | Brand mark: faceted mountain with a mine adit |
| `bergwork-pdf(-red).svg` | berg:work PDF: stone tablet with a dog-ear and chiselled lines |
| `bergwork-image(-red).svg` | berg:work Image: stone frame with mountain and sun |

`overview-round-1.png` shows each mark on dark and light, and as an app icon at 96/48/32/16 px.
`generate.py` creates all files, including the Himmel:CAD set: `python3 generate.py <out-dir>`.
