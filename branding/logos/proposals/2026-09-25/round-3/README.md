# Logo proposals 2026-09-25, round 3 (not approved)

Low-poly granite set in the style of the Himmel:CAD Builder mark. Earlier rounds: `round-1/`, `round-2/`.

| File | Proposal |
| --- | --- |
| `bergwork.svg` | Brand mark: Schlägel und Eisen, faceted |
| `bergwork-pdf.svg` | berg:work PDF: stone tablet with dog-ear, chiselled lines, first line red |
| `bergwork-image.svg` | berg:work Image: stone frame with mountain and red sun |

For white backgrounds every mark has two candidates:

- `-on-light-rim.svg`: a narrow mid-grey strip along the outer edges of the very light facets only
- `-on-light-tone.svg`: the very light facets on the outline are replaced by darker greys

`overview-round-3.png` shows dark / white rim / white tone / app icon at 96, 48, 32, 16 px.
`generator/generate.py <out-dir>` rebuilds all files, including the Himmel:CAD set (needs numpy, scipy, matplotlib).
