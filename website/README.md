# berg:work website v2

Production-oriented static product site for the two berg:work desktop apps. It is generated by a zero-dependency Node 22 build and makes no third-party runtime requests.

## Information architecture

| Route | Purpose |
| --- | --- |
| `/` | Factual brand introduction, product status and the recorded product commitments. |
| `/pdf/` | Tested PDF-editor capabilities, current limitations and the planned desktop app. |
| `/image/` | Capabilities in the current internal image build, roadmap context and explicit non-goals. |
| `/roadmap/` | Status of both products without unsourced dates. |
| `/download/` | Release-manifest-driven downloads; currently reports that no public builds exist. |
| `/legal/` | English legal notice preserving the provider and contact facts. |
| `/privacy/` | English privacy information including hosting, logs and service-worker storage. |
| `/offline/` | Offline fallback reached by the service worker. |
| `/404.html` | Not-found page for static hosting. |

## Build and preview

Node 22 is the only build dependency. From `website/`:

```bash
node build.mjs
node serve.mjs
```

The build writes clean routes and the root `404.html` to `dist/`. The preview defaults to `http://127.0.0.1:8080/` and serves `.webmanifest`, `.woff2`, images and video with explicit MIME types. For rebuild-on-change:

```bash
node build.mjs --watch
```

`site.config.mjs` is the single source for the site name, canonical origin, contact address, colours and product names. `siteUrl` is intentionally empty and marked `CONFIRM`; until it is set the build warns and omits canonical URLs, `og:url` and `sitemap.xml`.

## Content evidence

`CLAIMS.md` is the publication ledger. Every product feature, status, format, platform, number, pricing/licence statement and privacy fact is linked to repository evidence and labelled `WORKS`, `IN PROGRESS`, `PLANNED`, `OWNER` or `CONFIRM`.

## Media

`content/media.json` defines every screenshot and video slot. Missing files are omitted from HTML and reported as build warnings. The complete capture brief is in `MEDIA.md`.

To add media, place it in `src/media/` using the name in the manifest, then rebuild. Screenshot WebP companions are used automatically when present. A video slot is rendered only when both the MP4 and its poster exist.

## Releases

`content/releases.json` is the live release manifest. It starts with empty arrays, so the download page states “No public build yet” and renders no fake or disabled download controls. Notes use markdown-lite: plain paragraphs, `- ` list items and `**bold**`.

## PWA and caching

The build fingerprints CSS, JavaScript, fonts, hero images, icons and present media. `_headers` gives `/assets/*` a one-year immutable cache and keeps HTML, the manifest and service worker on `no-cache`.

The generated service worker precaches the application shell, uses network-first navigation with `/offline/` as fallback, and keeps a capped stale-while-revalidate cache for same-origin images and media. The privacy page documents this local Cache Storage use.

## Cloudflare settings

`wrangler.jsonc` points static assets at `./dist`. In the Cloudflare project, use:

- Root directory: `website`
- Build command: `node build.mjs`
- Output directory: `dist`

No deployment was performed as part of this work.

## Visual assets and font licence

The four mine heroes remain the identity images. Each has 2880×1620 and 1440×810 JPEG and WebP variants. The home page chooses one per load in `hero.js`; without JavaScript it shows `mine-dusk`. Mobile CSS keeps the existing per-image focal crop.

`Bergschrift-Regular.ttf` is a modified Stalinist One by Alexey Maslov and Jovanny Lemonad under the SIL Open Font License 1.1 (`src/assets/fonts/OFL.txt`). The Reserved Font Name required the Bergschrift rename. The site uses a WOFF2 containing the complete Latin-1, Latin Extended-A, Cyrillic and General Punctuation ranges from the source font. The source TTF remains available for regeneration with `../scripts/build-wordmark-font.py`.

The red/cream/ink palette, ruled grids, square corners, hard offset shadows, mine imagery and mountain mark carry forward from v1. Motion is limited to short hover/focus transitions and is disabled under `prefers-reduced-motion`.
